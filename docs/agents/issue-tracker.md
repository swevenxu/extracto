# Issue tracker

Issues and specifications for this repository live in GitHub Issues:

- Repository: `swevenxu/extracto`
- CLI: `gh`
- Create an issue with `gh issue create`
- Read issues with `gh issue view`
- List issues with `gh issue list`
- Comment with `gh issue comment`
- Apply labels with `gh issue edit --add-label`
- Close issues with `gh issue close`

Infer the repository from the Git remote, but verify the target before creating
the first issue. File issues only in `swevenxu/extracto`.

Pull requests are not a triage request surface for this repository. Triage
external pull requests only if this setting is intentionally changed.

The GitHub CLI was not available during setup. Install and authenticate it
before using skills that create or modify issues:

```sh
brew install gh
gh auth login
```
